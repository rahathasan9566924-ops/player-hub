# Permission submission guide (guardian-reviewed)

Updated: 2026-11-23

## Important status

No permission request has been sent. This repository cannot send external emails or submit legal/licensing forms on the project owner's behalf. These drafts must be reviewed and submitted by the project owner together with a parent/guardian.

## 1. PlayersDB

Official project information page:
https://playersdb.app/about

The About page says business inquiries, feedback, and database corrections should use the contact email shown in the site footer. It also says the project is independent and does not claim ownership of third-party intellectual property.

Action:
1. Open the official About page.
2. Use the Contact email shown in the footer (do not guess or use an address from an unofficial directory).
3. Ask for written confirmation that the maintainer has authority to grant the requested rights.
4. Ask separately about player IDs, factual attributes, derived/normalized records, bulk storage, public display, commercial use, updates, and attribution.
5. Do not upload/download and republish the dataset until written permission is received and reviewed.

## 2. eFootball Managers dataset maintainer

Repository:
https://github.com/amine250/efootball-managers

The repository currently has no published licence in the inspected tree. Its public README describes the dataset but does not itself grant redistribution rights.

Action:
1. Open the repository and use the maintainer's GitHub profile contact method, if one is published.
2. If no contact method is published, do not post project details publicly or create a public issue solely to request rights. Wait for a private contact route or use a different licensed dataset.
3. Ask for written permission to store, adapt, and publicly display the JSON records, and clarify whether photos are separately licensed.
4. Keep all records out of production until permission is clear.

## 3. KONAMI

For questions about the eFootball Terms of Use, KONAMI's official terms page identifies its customer support/inquiry route:
https://www.konami.com/games/inquiry/

The ordinary eFootball mobile in-game support form is for game inquiries and says it does not individually respond to opinions or requests. It should not be treated as a confirmed licensing channel.

Action:
1. Have a parent/guardian review the request.
2. Use KONAMI's general inquiry route and select the closest available category for a question about terms/licensing. If no suitable category exists, do not misclassify it as a gameplay bug; ask KONAMI to redirect the inquiry to its legal/licensing team.
3. Request explicit written permission or an approved data feed for factual player-card/manager fields, bulk storage, public display, and any commercial use.
4. Ask separately about images, card artwork, badges, and logos.
5. Do not scrape, reverse-engineer, or bulk extract game materials while waiting.

## Ready-to-send request text

Subject: Request for written permission to use eFootball player and manager data

Hello,

I am developing eFootball Zone 0.1, an independent fan-made information website. Before publishing any third-party dataset or eFootball game-derived data, I would like to request written permission and confirm the exact permitted scope.

Could you please confirm whether you have the authority to grant permission for the relevant data, and whether the following uses are allowed:

- Storing selected player identity fields, player-card attributes, manager names, tactical attributes, and stable identifiers in our own database;
- Normalizing the fields and using them for search, filtering, and comparison;
- Displaying the approved fields publicly on the website;
- Periodically updating the records;
- Commercial or monetized use, if any (please state explicitly whether this is allowed or prohibited).

Please specify the required attribution, any excluded fields, applicable limits, and whether photos, card artwork, club badges, and logos require separate permission.

We will not copy images or bulk data, or use scraping/reverse-engineering methods, unless expressly authorized. We will not imply endorsement by your organization or by KONAMI.

Please provide the applicable licence or written permission terms.

Thank you.
