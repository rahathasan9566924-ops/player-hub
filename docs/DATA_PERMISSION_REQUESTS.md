# Data reuse permission requests

These are draft messages only. They have not been sent. A parent/guardian should review any external licensing request before it is sent.

## 1. PlayersDB dataset permission

To: PlayersDB maintainers  
Subject: Permission request to use selected PlayersDB data in eFootball Zone 0.1

Hello PlayersDB team,

I am developing eFootball Zone 0.1, an independent fan-made information website for eFootball players and managers.

I found the PlayersDB project and its downloadable CSV/JSONL datasets. Before using any of the data, I would like to ask for written permission and clarification of the applicable licence.

Would you please confirm:

1. Whether you own or have authority to license the database contents.
2. Whether we may store selected player identity fields and identifiers in our own Supabase database.
3. Whether we may display those fields publicly on a non-commercial fan website.
4. Whether modification, normalization, search indexing, and periodic updates are permitted.
5. Which attribution wording and source link are required.
6. Whether any fields are excluded because they originate from KONAMI or other third parties.
7. Whether there are rate limits or other conditions for downloads and updates.

We will not copy player photos, card artwork, logos, or other images unless those rights are separately confirmed. We will not imply endorsement by KONAMI or PlayersDB.

Please share the exact licence or written permission terms that cover this use.

Thank you.

## 2. eFootball Managers repository permission

To: Maintainer of https://github.com/amine250/efootball-managers  
Subject: Permission request to reuse manager dataset in eFootball Zone 0.1

Hello,

I found your eFootball Managers repository and reviewed the structure of its manager JSON dataset. It appears useful for a fan-made manager reference section.

I could not find a licence file in the repository. Before copying or adapting any records, could you confirm in writing:

1. Whether you own or can license the manager dataset.
2. Whether public display and storage in our website database are permitted.
3. Whether commercial use is allowed or prohibited.
4. Whether modifications and periodic updates are allowed.
5. What attribution and source link you require.
6. Whether manager photos have separate rights and must be excluded.

We will not copy the dataset or its images until reuse permission is clear.

Thank you.

## 3. KONAMI permission / clarification request

Subject: Request for permission or clarification on eFootball factual data display

Hello KONAMI Support/Legal Team,

I am developing an independent fan-made eFootball information website. I would like to understand whether KONAMI grants permission, or provides an approved data feed/licence, for displaying selected factual player-card and manager attributes from eFootball in a searchable public reference website.

We will not access game files through reverse engineering, modify the game, automate interaction with the game, or scrape KONAMI services. We would only proceed using a source or method expressly authorized by KONAMI.

Could you please advise:
- Whether an official API or licensed data programme exists;
- Whether selected card attributes, ratings, player names, manager tactical values, and release information may be stored and publicly displayed;
- Whether separate permission is needed for card artwork, player images, club badges, and logos;
- Whether non-commercial fan use is treated differently from commercial use.

Thank you.
